# 格式与回填协议

[English](FORMAT.md) · [简体中文](FORMAT.zh-CN.md)

## 支持的子集

SRT：独立数字编号、`HH:MM:SS,mmm --> HH:MM:SS,mmm` 时间行、至少一行非空正文和空行分隔。编号不必连续；不支持时间行扩展后缀和未知块。

WebVTT：文件以 `WEBVTT` 开始，使用空行分隔，字幕标识可省略；存在时须唯一。时间支持 `MM:SS.mmm` 或 `HH:MM:SS.mmm`。条目按开始时间排序，允许重叠。保留文件头、NOTE 和第一条字幕之前的 STYLE／REGION 块，时间行的位置设置文字原样保留，但不验证全部 WebVTT 规范与标记渲染语义。

两种格式均要求结束晚于开始、正文非空，Unicode 有效且不含不支持的控制字符。正文包含 `-->` 会被拒绝。不支持空正文条目、ASS／SSA 文件、自动编码识别、调时轴、重新切段、语音识别或视频渲染。仅接受 UTF-8。

回填只替换正文区间，不通过通用序列化器重写原文件。原时间行、编号、元数据和分隔符保留；译文采用各条原字幕的换行方式。

## 任务对象

```json
{
  "schema": "cuebridge/v1",
  "projectId": "sha256:<64 lowercase hex digits>",
  "batchId": "batch-001",
  "targetLanguage": "zh-CN",
  "entries": [
    {"id": "cue-000001", "source": "Hello.", "translation": ""}
  ]
}
```

AI 返回相同对象，只将 `translation` 填为非空译文。`projectId` 是解码后的完整原文重新编码为 UTF-8 所得的 SHA-256；文件导入时包含开头 BOM 和原换行。固定 ID 按原字幕顺序生成，与字幕自身的编号或标识不同，只对完全相同的原文保持稳定。

工具按当前项目检查批次成员，回复顺序可改变。未知 ID 不会原样显示在错误里。原文改变、项目／批次／目标语言错误、ID 缺失／重复／未知、译文为空或多余条目，都会阻止接受。只有原文件、语言和批次成员匹配，才可复用保存的回复。

`<...>` 标签、内嵌时间戳和 `{\...}` 样式标记须完全一致且顺序不变。这只检查标记保留，不判断语义或完整标签规则。译文不能有首尾换行、空白行、`-->`、不支持的控制字符或内嵌 BOM。最终输出会再次解析，并核对时间行和原标识。

原文／输出上限 2 MiB，单个回复 4 MiB；最多 10,000 条；每条原文／译文最多 10,000 字符；每批 1—100 条、最多 12,000 个源字符。字符限制按 JavaScript 字符串长度计算。即使原文件符合上限，较长译文也可能让输出超限。
