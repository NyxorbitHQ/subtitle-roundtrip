# 项目取舍与资料

[English](RESEARCH.md) · [简体中文](RESEARCH.zh-CN.md)

核对日期：2026-10-20。待验证的假设是：在字幕文件与自选 AI 服务之间，提供小型、可检查的交接流程是否方便。不声称市场空白、已有付费意愿或保证收入。

[WebVTT 规范](https://www.w3.org/TR/webvtt1/) 用于核对时间与块保留规则。[美国国会图书馆 SRT 说明](https://www.loc.gov/preservation/digital/formats/fdd/fdd000569.shtml) 描述了编号、时间和文本块，以及编码缺乏统一标准的情况。本版有意只接受 UTF-8 与保守子集，不声称完整规范兼容。

[Subtitle Edit](https://github.com/SubtitleEdit/subtitleedit) 已是成熟字幕编辑器。CueBridge 不代替完整编辑器，也不声称翻译工作流无人解决。它聚焦固定 ID 分批、原文件绑定、严格回复校验与本地回填，无需 API Key。

先验证实际使用，再考虑商业功能：向自愿参与者了解能否完成获授权任务、哪些回复被拒绝、原来用什么和是否复用，不收集真实文件。尚无访谈、留存统计、销售或付费验证。后续支持服务或集成仍需另行验证需求与交付成本，MIT 开源本身不构成商业验证。
