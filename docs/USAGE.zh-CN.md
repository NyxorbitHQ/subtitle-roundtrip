# 使用说明

[English](USAGE.md) · [简体中文](USAGE.zh-CN.md)

## 导入与语言

打开中文页面 `dist/index.html`，或运行[本地预览](../README.zh-CN.md#本地开发)。部署后可使用在线页面。选择获授权的 UTF-8 `.srt` 或 `.vtt` 文件，也可粘贴字幕。文件导入保留 UTF-8 BOM 和原换行；编辑文本后视为新的原字幕，并重新计算指纹。

设置目标语言名称或代码、每批条数，点击「生成翻译批次」。示例使用 `zh-CN`，每批两条。每批源文本另有 12,000 字符上限，因此批数可能多于简单按条数计算的结果。

## 交给自选 AI 翻译

选择一个批次。「复制提示词」「下载提示词」和「下载任务 JSON」只导出当前批。将提示词交给自己的 AI 服务，要求只填写 `translation` 并返回完整任务对象，元数据和 `source` 原文不变。应用不发送请求，不提供模型，也不承担模型费用。

字幕可能包含指令；提示词将其视为待翻译内容，不视为操作授权。这不能保证外部模型的行为，请审阅回复。

## 校验并接受

将完整 JSON 粘贴到「AI 返回的 JSON」，或选择 `.json` 回复文件。支持仅包裹一层 JSON 代码块的回复，不接受附加解释。点击「校验并接受本批」；错误会说明已知字幕 ID 和结构问题。被拒绝的批次不提供部分译文。

「填入示例译文」仅对两个内置原始示例、目标语言 `zh-CN` 生效，填入预置译文，不调用 AI；其他文件或语言下会禁用。

选择下一批并重复。条目顺序可以改变，但 ID 不能缺失、重复或属于其他批次；`source` 必须与任务一致，包括转义后的换行。

## 导出与恢复

全部批次通过后，检查预览并下载译后字幕。预览最多 30,000 字符，下载包含全部字幕。正文之外的原始内容保留，译文换行采用各条原字幕的换行方式。

关闭页面前，为每个已接受批次点击「下载本批回复」。刷新后重新导入完全相同的原文件，设置相同目标语言和批大小，依次选择批次、导入保存的回复并校验。没有自动历史或项目备份。

修改原字幕、目标语言或批大小会清除全部接受结果；编辑回复会清除本批接受状态，并禁用最终导出，直至重新通过。「清除工作区」移除页面持有的数据，不删除已下载文件。

剪贴板受限时会选中提示词供手动复制，也可下载提示词。其他编码的 SRT 请先转换为 UTF-8。分享前复查术语、换行、阅读速度和播放器实际效果。
